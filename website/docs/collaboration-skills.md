# Collaboration Skills for Big System Projects

Environmental systems work often involves audits, models, proposals, observations, community projects, and shared responsibility. Collaboration helps kids divide big systems work into roles, check-ins, and fair contributions — without making one person responsible for fixing everything.

This page is the local doorway into the Literacy for Kids [Collaboration Toolkit](https://www.literacy-for-kids.com/docs/toolkits/collaboration), connected to the systems thinking this curriculum builds.

## A few core ideas

- **Big system projects need shared goals.** One target the whole group can name.
- **Roles help groups manage audits, models, and proposals.** Counter, recorder, question asker, goal checker.
- **Fair work matters when projects are large.** Big projects make silent unfairness easy.
- **Community action needs check-ins and repair.** Long projects hit messes; groups recover.
- **No one has to fix a whole system alone.** Shared responsibility is the point.

## When this shows up

- When running an audit
- When building a system model
- When preparing a proposal
- When working with a group
- When revising after feedback
- When a project feels too big
- When community action needs roles

## Tools that help

- **Shared environmental goal** — one loop, one place, one question the group owns together.
- **Audit role checklist** — who counts, records, asks, and checks the goal.
- **One-loop group focus** — the group works one loop at a time.
- **Check-in questions** — what is done, stuck, or needs help?
- **Finish together credit** — every contribution named at the end.

:::tip Collaboration Moment
A big systems project needs shared roles. One person can track observations, one can draw the model, one can ask questions, and one can check the goal. Collaboration helps the group work on the system without one person carrying the whole thing.
:::

:::caution Everyday collaboration skills, not unsafe conflict management
These are everyday collaboration tools, not therapy, bullying intervention, conflict mediation, legal advice, or a replacement for trusted adults, educators, caregivers, or qualified support. Kids should not be expected to manage unsafe, coercive, bullying, discriminatory, or threatening group situations alone — and no child has to fix a whole system by themselves. If group work feels unsafe, targeted, or too big, involve a trusted adult.
:::
