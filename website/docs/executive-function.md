# Executive Function Skills for Big System Projects

Environmental systems work often includes audits, diagrams, models, proposals, observations, revisions, and group projects. Executive function helps make big systems work smaller, visible, and easier to restart.

This page is the local doorway into the Literacy for Kids [Executive Function Toolkit](https://www.literacy-for-kids.com/docs/toolkits/executive-function), connected to the systems thinking this curriculum builds.

## A few core ideas

- **Big system projects need small entry points.** Start with one loop, one place, or one material.
- **Audits work better with checklists.** Visible steps keep an audit organized.
- **Diagrams and models need revision steps.** A first draft is not the final one.
- **Proposals need roles, priorities, and deadlines.** Shared work needs a plan.
- **You do not have to fix a whole system alone.** Big problems are shared work.

## When this shows up

- When a system feels too big
- When running an audit
- When drawing a loop or model
- When building a proposal
- When revising after feedback
- When working with a group
- When returning to a long project

## Tools that help

- **Audit checklist** — the same steps each time.
- **One-loop focus** — one part before the whole system.
- **Proposal next-step tracker** — what happens next, and who.
- **Role checklist** — who does what in the group.
- **Restart bookmark** — for long, multi-session projects.

:::tip Executive Function Moment
A big system project needs a tiny entry point. Start with one loop, one place, or one material. "Study waste" is huge; "count what is in one trash bin" is startable.
:::

:::caution Everyday task skills, not a diagnosis
These are everyday planning and task-management tools, not therapy, medical advice, disability evaluation, ADHD treatment, or a replacement for trusted adults, educators, caregivers, or qualified support. Kids should not be treated as lazy or broken when starting, focusing, organizing, or finishing is hard, and you do not have to fix a whole system by yourself. If tasks feel consistently overwhelming, inaccessible, unsafe, or severely distressing, involve a trusted adult and appropriate support.
:::
